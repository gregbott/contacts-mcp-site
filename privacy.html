Privacy policy

Last updated November 5, 2026

Contacts MCP is a personal tool used only by its developer. This policy describes how it handles Google user data.

Data accessed

With the user's consent, Contacts MCP accesses the Google Contacts of the signed-in account through the Google People API: names, email addresses, phone numbers, organizations, addresses, birthdays, relations, notes, and contact labels. It also reads the "Other contacts" list.

How the data is used

Contact data is used only to carry out requests the user makes. For example, it can look up a contact, add a phone number, or update a note. The tool runs on the user's own computer. It returns results to the AI assistant client on that computer, which may send them to the assistant's model provider to answer the request.

Storage

Contacts MCP does not keep a copy of contact data. The only thing it stores is the OAuth sign-in token, in a file on the user's computer that only the user can read. It has no server, database, analytics, or advertising.

Sharing

Contacts MCP does not sell, rent, or share Google user data with anyone. It does not use the data for advertising, and it does not use it to train AI models.

Google API Services User Data Policy

Contacts MCP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file also removes access.

Contact

Questions can be sent to the support email shown on the Google consent screen.
