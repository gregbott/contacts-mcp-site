Contacts MCP

Contacts MCP is a personal tool that lets an AI assistant running on its owner's own computer search and update that person's Google Contacts. It is a small program that runs locally and connects to the Google People API with the owner's permission.

It is not a public service. It has one user, its developer, and it does not offer sign-up or accounts.

What it does

  • Searches and reads contacts in the signed-in Google account
  • Creates, edits, and deletes contacts and contact labels when the user asks
  • Searches Google's "Other contacts" list (read-only)

See the privacy policy for how data is handled.
